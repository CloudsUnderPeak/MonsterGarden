# 小怪物拖曳互動

## 操作

滑鼠左鍵按住或單指按住怪物即可拿起，移動指標帶著怪物走，放開後落回地面。拖曳期間怪物停止自行走動，透過快速搖擺、身體伸縮和懸空陰影呈現掙扎。其他怪物繼續活動。

放開後短暫落下、落地擠壓，再恢復活動。天空與畫面外的放開位置會收回可活動區；池畔放開時避免落入水中。按 Escape、視窗失焦或指標中斷時安全放下，不會讓怪物卡在被抓取狀態。

減少動態偏好啟用時仍能拖曳，改用固定的懸空姿勢，不播放持續掙扎或落地動畫。

## 分工

- `src/ui/creature-drag.js`：使用 Pointer Events 統一滑鼠、觸控與手寫筆。指標擷取維持跨出畫面的拖曳，視窗事件作為備援。多指操作不搶走目前抓取，拖曳放開不觸發地面吸引。
- `src/creatures/simulation.js`：管理抓取、移動、放下與落地狀態；抓取時跳過自主移動和腳印更新。切換場景、重分布與重建居民會解除抓取。
- `src/rendering/creature-renderer.js`：共用繪製與命中姿勢，反轉旋轉、翻轉與縮放後判斷圖片範圍。可讀像素時使用快取透明遮罩，讓點擊透明處能穿透；本機像素讀取受限時使用圖片邊界判斷。
- `src/rendering/world-renderer.js`：被抓取的怪物最後繪製，避免被地面居民或特效遮住。

拖曳只改變執行中的角色狀態，不修改怪物原始圖片，不新增網路請求。
