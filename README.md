# Monster Garden

滿版的小怪物生態箱。看牠們在微風草原、月光池畔與靜靜雪原裡，自由走動、探索和休息。

[開啟線上網站](https://cloudsunderpeak.github.io/MonsterGarden/)

## 使用方式

- 在右上角的下拉選單切換場所。
- 點擊地面，吸引小怪物靠近。
- 也可以直接雙擊專案的 `index.html`，在本機開啟。

支援 PNG / AVIF 圖片，透過伸縮、搖擺、轉向與彈跳，讓單張圖片活起來。網站只使用專案提供的怪物圖片，沒有示範角色。
